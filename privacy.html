Privacy Policy

Network Ledger · last updated 20 November 2026

Network Ledger is a private tool that runs on its owner's own server. It is not a public service and has no sign-up. This policy explains what it does with Google account data when its administrator connects Google Drive.

What Google data it uses

  • The account's email address: only to show which Google account is connected.
  • Files it creates in Google Drive: its own backup files and report files, kept in a folder it creates. With the drive.file permission it can only see and change these files. It cannot see any other file in the Drive.

How the data is used and kept

  • The data is used only to upload, list, download and remove Network Ledger's own backups and reports.
  • The Google sign-in token is kept only on the owner's own server and is never shown or sent anywhere other than to Google.
  • No data is sold, shared with anyone, or used for advertising or to train AI models.
  • The use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access and data

  • Press Disconnect on Network Ledger's Backup page, or remove "Network Ledger" at myaccount.google.com/permissions.
  • The backup and report files stay in your Drive until you delete them, like any other file you own.
