Network Ledger

A private network reporting tool, run on its owner's own server.

Network Ledger collects traffic and active-user figures from network monitoring systems, and builds daily reports, dashboards and network maps for an internal network operations team.

How it uses Google

  • When its administrator connects a Google account, Network Ledger saves its own backup files and report files into a folder of that account's Google Drive.
  • It can only see and change the files it created itself (the Google Drive drive.file permission). It cannot read any other file in the Drive.
  • It reads the account's email address only to show which account is connected.
